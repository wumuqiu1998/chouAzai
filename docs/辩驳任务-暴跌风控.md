# 辩驳任务包：暴跌风控方案（2026-08-11）

## 一、辩驳对象（正方主张）

基于 `run_crash_risk_study.py`（6845 个暴跌事件）与 `run_crash_classify.py`（14578 个事件）：

- **P1 不接飞刀**：个股首次暴跌（单日 ≤-7% 且前一日 >-9%）后 5 个交易日内不买入；
  证据：D+1~5 行业中性超额 -0.89%（t=-7.75），伪事件对照 +0.24%。
- **P2 跌停级更危险**：≤-9% 组 D+1~20 -2.97%（t=-8.19），小盘股 -3.32%（t=-11.96）；
  应延长回避至 20 日。
- **P3 分级风险**：高位（前60日>30%）+ 缩量 + 未破位 = 最高风险（D+1~20 -3.31%，
  t=-4.90）；放量 + 破位 + 板块共振相对企稳（+0.38%，不显著）。
- **P4 指数级暴跌区分**：上证单日 ≤-1.5% 后 1~3 日反弹（+0.56%/+0.95%，n=14），
  与个股利空暴跌逻辑不同。
- **P5 落地**：在看盘工具中实现暴跌警告 + 分级风险提示。

## 二、正方证据清单（仓库内可复核）

- `data/crash_risk_study.md`：暴跌事件分组收益表；
- `data/crash_classify.md`：洗盘/出货/利空判别分组表；
- `data/volume_price_health.md`：量价因子体检（高位风险与量比负 IC 交叉验证）；
- `experiments.csv`：CRASH-* / CLASSIFY-* 实验记录。

## 三、反方必须质疑的方向（最低清单）

1. **样本与选择偏差**：缓存池 3606 只来自抽样+业绩预告事件股，非随机全市场；
   单一年窗口（2025-08~2026-08）是否只是特定行情的产物？
2. **数据质量/复权**：新浪不复权 K 线，除权除息日跳空会被误判为“暴跌事件”，
   事件样本有多少是假的？
3. **执行可行性**：跌停股次日一字板卖不出/买不进，R1（次日减仓）是否可执行？
   费用/滑点未计入。
4. **多重检验**：12 个分组是看完数据后挑的，“缩量=危险”等反直觉结论
   会不会是特定年份的过拟合？
5. **机会成本**：只统计“暴跌后买入的损失”，没统计“回避后错过的反弹”——
   风控规则的净收益（省下的亏损 − 错过的收益）是多少？
6. **消息面缺失**：研究用暴跌代理利空，没有消息数据，无法区分
   “有消息的暴跌”与“无消息的错杀/恐慌”。
7. **对照组合理性**：伪事件对照是同股票随机日期，但暴跌股与随机日期的
   “超跌状态”不同，是否应加同行业同跌幅对照？
8. **P4 样本过小**：指数暴跌仅 14 个样本，结论不可靠。
