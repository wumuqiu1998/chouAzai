# 量化教训总结：缠论信号翻车事件（2026-08-11）

## 一、发生了什么

项目长期以“缠论买点”为核心信号，此前验证结果：
方向准确率 71%~74%、单笔超额 +3.17%、组合收益 +64.5%。
2026-08-11 把卖出信号纳入截断一致性测试后，抓出三类未来函数，
修正口径重跑全部核心实验：

| 指标 | 修正前 | 修正后 |
|---|---|---|
| 缠论买点 5 日方向准确率 | 71%~74% | **49%** |
| 单笔净收益超额 | +3.17% | **+0.05%** |
| combo_top5 组合收益 | +64.5% | **-16.4%** |
| 持有 20 日超额（同板块异股对照） | — | **-2.81%** |

结论：之前所有正收益主要是未来函数造成的假象，策略本身没有可验证的 alpha。

## 二、根因：未来函数有三层，我们只防了两层

1. **计算层**（指标公式）：MA/ATR 只用历史数据——已防；
2. **执行层**（成交时点）：信号确认后才 T+1/T+2 成交——已防；
3. **选择层**（信号身份）：**“哪个点算有效买卖点”本身由未来结构决定**——未防。

缠论买卖点要等“下一个反向分型”确认后才固定；在确认之前，同一个走势可能
先标 11-28、后续数据到达后重标成 12-03。全量数据算一遍再挑点，等于回测时
提前知道哪些点“最终成立”——这就是 71% 的来源。SMC 扫荡同样存在
“用全量最新摆动点判断历史 K 线”和“按未来数量截断信号”两个问题。

## 三、为什么“多次强调不用未来函数”还是漏了

- 强调的是原则，没有变成**机械测试**；原则不会自动拦人；
- 已有截断测试只覆盖了指标计算（ATR/缠论/板块状态），没有覆盖
  回测实际使用的**信号映射表**；
- 旧测试用的合成数据恰好没触发重标，给了“测试通过”的假安全感；
- 对抗审计查了参数、样本、成交时点，但没有检查“信号身份稳定性”，
  而这一条恰恰是唯一能抓住重标的检查。

## 四、防再犯机制（已固化到 AGENTS.md 与 quant-strategy-kit skill）

1. **无未来函数三层全部可测**：新增
   `test_exit_signal_maps_no_lookahead`（卖出信号映射表截断一致性）、
   `test_chan_locked_no_lookahead`（锁定缠论单调性）、
   `test_chan_locked_no_lookahead_minute`（分钟级）、
   `test_t_backtest_end_date_no_future_effect`（做T追加未来数据不影响历史窗口）；
2. **信号准入五道关**：假设卡 → 单测 → 截断一致性 → 随机+同板块异股基准 →
   参数固定样本外，全部通过才能标“已验证”；
3. **强制两轮正反辩驳**：所有策略制定必须经过正方提出证据、
   反方唱反调、正方答辩、反方复辩四步，文档留档后才可进入下一步；
4. **结论口径统一**：缠论一律用 `analyze_chan_locked`，SMC 逐 bar 因果化，
   旧全量口径结论全部撤回。

## 五、正面收获

- 在实盘/模拟盘之前抓住问题，代价只是回测结果作废；
- 得到一套真正可复用的无未来函数测试基建，今后任何新信号都能快速证伪；
- 用同板块异股对照、持有期扫描、置换检验等方法，把“候选”和“已验证”
  的边界彻底划清——这比任何一个“好策略”都值钱。
