## 二、反方复辩（第三轮）

1. **低位/放量/破位组样本外 t<2**：方向虽转为一致，但统计力不足，
   只能算“相对不差”，不得写成“可以抄底”信号——同意，保留为风险分级而非信号；
2. **有消息组样本仅 43 个且样本内 t=-0.13**：V2 的“消息升级”结论不稳定，
   只能作为方向提示，且消息源仅业绩预告（减持/立案批量接口不可用，外部限制）；
3. **样本外仍只有 2024-08~2025-08 一年**：更早年份（2023-2024）未验证，
   规则需季度复核；
4. **回避型规则无收益上界**：它只省亏损、不创造收益，定位必须是“风控提醒”，
   禁止包装成收益策略；
5. **一字跌停卖不出 3.3%**：R1 需加例外——次日一字跌停则继续持有，次日再评估。

## 三、正方终辩与判定

接受 1~5。核心规则（首次暴跌后 20 日不买入、高危特征分级、R1 次日评估减仓）

方向稳定，判定为 **“提示层”候选通过**。

**允许集成，但必须同时满足：**
1. 定位为看盘风控提醒，不是交易策略、不产生收益预期；
2. 不使用“洗盘/出货/利空”标签，只给风险等级；
3. “有消息升级”仅限业绩预告类消息，注明数据源限制；
4. R1 例外：次日一字跌停不强行卖出；
5. 每季度用新增数据复核一次，任一分组方向反转即降级。
