## 核心观点

1. 所有指标的数据源都是 K 线的开高低收四个要素，二次加工越多越失真——
   好比清蒸鱼能吃到原味，放太多辣椒调料，丢一坨死鱼进去都"好吃"。
2. 越接近原始价格（裸K、结构、关键位）越有效；指标派天然滞后、怕震荡。
3. 除"价格维度"外还有独立的"资金面维度"（订单流、威科夫、量价/筹码），
   底层逻辑是散户人多钱少不理性、大户低位吸筹高位派发。
4. 交易方法没有绝对好坏，用结果说话（黑猫白猫，抓到老鼠就是好猫）。
5. 波浪/缠论/道士这类结构理论必须用"推演式"用法：先假定结构，错了就止损，
   不能等行情走完再数浪（那是未来函数/事后画靶）。

## 评级总表（从高到低）

### 顶级

| 流派 | 评价 |
|---|---|
| 价格行为 Price Action | 最原始、最直接；裸K/吞没/插针/趋势线/关键位；**保留"下扫"信号**（大资金拉升前爆掉散户止损位的动作），指标加工后会丢失；关键位跨周期有效。缺点：单看 pin bar 可能继续创新高，需结合关键位与结构。 |
| 道士理论 Dow Theory | 裸K趋势判断：低点抬高+高点抬高=上升，反之下降；可顺势回调进场或判断趋势变化。缺点：高低点定义模糊、信号右侧，需推演式使用。 |
| 海龟交易 | 首次把交易系统化/量化：固定止损、客观出场、趋势跟踪；量化交易鼻祖。缺点：只吃大趋势，震荡反复亏损，出场右侧利润回吐大。 |
| 订单流 Order Flow | 资金面维度，直接看盘口微观结构（Footprint 脚印），跟随大资金/做散户对立面。缺点：本质高频、盯盘消耗巨大；市面卖课多，散户落地存疑。 |
| 威科夫 Wyckoff | 资金面维度鼻祖：吸筹→拉升→派发→下跌→再吸筹的循环；提供完整分析框架，可搭配其他工具。 |
| ATR | 工具型指标（平均波动率）：日内波动超过 N 倍 ATR 不再追涨；用 N 倍 ATR 设支撑/止损（海龟同款）；不分析行情但极好用。 |

### 优秀（可用）

| 流派 | 评价 |
|---|---|
| 均线 | 最简指标、其他指标之祖；趋势极强时好用（金叉死叉右侧）；回调均线是心理位（可作支撑参考）；震荡行情反复打损。 |
| RSI | 超买超卖/反身性指标：极度狂热见顶、绝望见底；**趋势中会失效**（月线99还能涨）；适合与关键位叠加使用。 |
| 量价分析 | 价格+成交量互证（顶部放量=出货）；是组合工具，不是独立体系。 |
| VPVR 成交量分布 | 每个价格的成交量，密集区=支撑阻力；辅助工具。 |
| 筹码分布 | 看持仓成本，A股有效（无场外交易）；黄金等有场外/冰山订单失效；只能辅助。 |

|---|---|

## 与当前量化项目的关联

- **缠论**被评为"中等但可用"：作者强调正确用法是**推演式**（假定买点→破位止损），
  不是预测。我们项目里的缠论 B/S 点做T正是这个思路：信号次日执行 + 收盘强制回补，
  从不假设走势必然延续。
- **量价确认**：我们已实现的中枢+量价（缩量低吸/放量高抛）与视频"量价是完善系统的工具"
  的判断一致——它不能独立成体系，但能过滤信号、减亏。
- **ATR 工具**可以落地到我们的风控：日内波幅超过 N×ATR 时停止追涨/追空，
  以及用 ATR 倍数设置做T的止损位。
- **板块状态切换**本质是"道士理论+趋势跟踪"的现代应用：顺势做多T/做空T、
  震荡双向，与作者"趋势为王，顺势而为"一致。
- 作者"越接近原始价格越有效"的理念支持我们直接基于 K 线结构（分型/笔/中枢）
  而非二次指标构建信号。
