# ICT / SMC（聪明钱概念）详细分析

## 一、是什么

- **ICT**（Inner Circle Trader，内圈交易者）：Michael Huddleston 创建的日内交易框架，
  核心主张是**价格行为本质是机构（做市商/聪明钱）流动性操作的痕迹**。
- **SMC**（Smart Money Concept，聪明钱概念）：ICT 的简化/商业化版本，
  去掉大量自创术语、保留核心结构逻辑，在 YouTube 和国内量化社区流行。

视频作者杰明GW 的评价：逻辑本身值得学（是价格行为+威科夫的现代结合版），
但 ICT 自创术语太多、"非常装逼"；建议先学原版价格行为/威科夫，再学 SMC。

## 二、底层假设

1. 市场由机构资金主导，散户是"流动性提供者"（止损单、追涨杀跌单）。
2. 机构需要对手盘成交，因此会主动制造**流动性陷阱**：先突破前高/前低
   扫掉聚集的止损单（Stop Hunt），拿到流动性后再反向运行。
3. 机构建仓会留下痕迹：订单块（OB）和公平价值缺口（FVG）——这些是
   可观察、可标注的 K 线结构。
4. 因此研究重点从"指标预测"转向"结构读取"：识别聪明钱在哪个价位收集/派发。

## 三、核心概念

### 1. 流动性（Liquidity）
- **BSL（Buy-side Liquidity）**：前高上方的买入止损聚集区（追多者的止损）。
- **SSL（Sell-side Liquidity）**：前低下方的卖出止损聚集区（割肉者的止损）。
- 价格会"顺路"去扫这些流动性：突破 BSL 后反转=扫多，跌破 SSL 后反转=扫空。

### 2. 流动性扫荡（Sweep / Stop Hunt）
- 形态：价格突破最近前高/前低，但**收盘收回**突破位内侧。
- 含义：止损被扫掉后，推动力量消失，行情常反向（这是 SMC 最强的反转信号之一）。
- 我们实现：突破 swing high/low 且当根收盘收回 → 标记 sweep（看跌/看涨）。

### 3. 公平价值缺口 FVG（Fair Value Gap / Imbalance）
- 定义：三根 K 线中，K1 的高点与 K3 的低点之间存在未被覆盖的缺口区间
  （看涨 FVG：K1.high < K3.low；看跌 FVG 相反）。
- 含义：缺口 = 价格移动过快留下的"失衡区"，市场倾向回补后再延续。
- 用法：回踩 FVG 是低风险入场区；FVG 被填满则失衡修复。
- 注意：FVG 是**描述性结构**，不是预测；需结合方向/更高周期。

### 4. 订单块 OB（Order Block）
- 定义：一段反向推进前的最后一根 K 线（例如连续下跌后第一根放量阳线），
  被认为是大资金建仓的"脚印"。
- 用法：价格回踩 OB 区间（low~high）是潜在入场区；跌破 OB 则假设失效。
- 我们实现：连续 2+ 根阴线后的阳线 → 看涨 OB；对称看跌 OB。

### 5. 市场结构（Market Structure）
- **BOS（Break of Structure）**：突破同向前高/前低，趋势延续。
- **CHoCH（Change of Character）**：反向突破（如上升趋势中跌破前低），
  趋势可能改变——SMC 中最关键的转折信号。
- 用法：HTF（高周期）看方向，LTF（低周期）等 CHoCH 后找入场。

### 6. 时间框架嵌套
- 经典流程：日线/4H 定方向 → 1H/15m 等回踩 → 5m/1m 找精确入场。
- 与我们项目的板块状态/市场趋势天然互补：市场趋势=HTF 方向，
  K 线结构（SMC）=LTF 入场。

## 四、交易逻辑（顺趋势 + 结构入场）

1. HTF 方向向上 → 只找看涨结构（FVG/OB 回踩、SSL 扫荡）；
2. 等待 LTF 出现 BOS/CHoCH 确认方向没有被破坏；
3. 在 FVG/OB 区间挂单，止损放结构外（OB/FVG 边界外 1×ATR）；
4. 目标=下一流动性池（前高/前低/等幅）。

这与我们现有框架的契合点：
- 市场趋势（道士/板块状态）= HTF 方向过滤；
- 威科夫成本区 = 判断 OB/FVG 是否在主力成本附近（共振更有效）；
- ATR = 止损/目标距离的统一度量。

## 五、局限与风险

1. **事后性**：BOS/CHoCH/FVG 都需要右侧确认，等确认时行情已走一段，
   是"结构确认"而非"预测"——和缠论一样，必须用推演+止损。
2. **A 股 T+1**：日内扫荡反转策略在 A 股不能当日买入卖出，只能隔日，
   信号到执行的延迟会降低胜率，需回测验证。
3. **跳空限制**：A 股有涨跌停，极端行情 FVG 可能无法回补。
4. **过拟合风险**：SMC 术语多、规则软，容易"看图说话"；必须用
   固定的结构定义 + 截断一致性测试（无未来函数）来约束。

## 六、本项目的实现

`quant_framework/smc.py` 实现了四个可审计概念：

| 概念 | 实现 | 输出 |
|---|---|---|
| FVG 公平价值缺口 | 三根 K 线缺口，T+2 确认，标记是否已回补 | fvg[] |
| OB 订单块 | 连续 2+ 反向 K 线后的第一根推进 K 线 | ob[] |
| 流动性扫荡 | 突破 swing 高/低后当根收盘收回 | sweeps[] |
| BOS/CHoCH | 最近 swing 序列的方向突破/反向突破 | structure |

前端 K 线图将提供开关叠加 FVG 色块、OB 区间、扫荡标记和结构状态。
