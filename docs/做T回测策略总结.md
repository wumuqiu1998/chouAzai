# 做T回测策略总结

> ⚠️ **结论待重验（2026-08-11）**：做T引擎本身是逐 bar 前缀计算（无未来函数，
> 已新增 end_date 截断一致性测试），但本文的策略收益结论依赖缠论/ATR/SMC 信号源，
> 这些信号在修正锁定口径后的有效性尚未重新验证；收益集中度等描述性结论不受影响。

> 基于 `backend/quant_framework/run_t_comparison.py`（基础对比）与
> `run_t_regime_comparison.py`（板块状态对比）的真实回测结果整理。
> 原始数据：`data/t_comparison_report.md`、`data/regime_report.md`（均不入库）。

## 一、统一回测口径

| 项目 | 设定 |
|---|---|
| 底仓 / 单次T量 | 底仓 1000 股，每次半仓 500 股 |
| 佣金 | 0.03% × 2（双边） |
| 印花税 | 0.05%（卖出；516080 ETF 为 0） |
| 滑点 | 0.01% |
| T+1 | 只能卖底仓、当日买回，收盘强制回补 |
| 信号执行 | 信号下一根 K 线开盘价成交（无未来函数） |
| 回测窗口 | 30分 ≈ 100 交易日；15分 ≈ 50 交易日 |
| 数据源 | 腾讯 K 线（个股）+ 东财/同花顺板块指数日K（板块状态） |

## 二、七个策略变体

### 1. B/S 点做T（缠论买卖点）
信号：缠论一/二/三类买卖点，S 点卖出底仓、B 点买回。
特点：信号稀疏（8~24 对/期），费用低；顺趋势做空T为主。

### 2. 中枢上下轨做T
信号：最近完成中枢，跌破 ZD（下沿）低吸 / 突破 ZG（上沿）高抛。
特点：信号密集（40~96 对/期），交易频繁，费用高；先买后卖/先卖后买均可。

### 3. 中枢 + 量价确认
在 2 基础上加量能过滤：缩量（≤ 20日均量 0.85）才低吸，放量（≥ 1.15）才高抛。
效果：减少无效触发，降低费用。

### 4. 中枢 + 个股MA20趋势过滤（组合型）
日线收盘 vs 前一日 MA20 定方向：上升日禁开空、下跌日禁开多。
效果：显著降低交易次数（90 对 → 22~49 对）与费用。

### 5. 中枢 + 量价 + 趋势
3 与 4 叠加，进一步收敛信号。

### 6. B/S + 板块状态切换
所属板块指数日K（东财/同花顺）三态分类：上升→做多T（B点买入→S点卖出）、
下跌→做空T（S点卖出→B点买回）、震荡→双向。

### 7. 中枢 + 板块状态切换
同上，但中枢触发按状态限腿：up 只做多腿、down 只做空腿、range 双向。

## 四、策略横向对比结论

1. **B/S 是最稳定的正收益源**：300223 30分（+27199）、600487 15分（+13428）两只贡献了绝大部分利润；其余股票 B/S 接近打平。
2. **中枢策略普遍输在交易频率**：80~96 对 vs B/S 的 8~24 对，费用（2000~7000 元）直接吃掉利润；趋势/板块状态过滤的核心价值是**砍交易次数**。
3. **量价确认**：有效减亏（如 600487 15分 中枢 -19468 → -4354），但不足以翻正。
4. **趋势过滤（个股 MA20）**：对 000636 有效（-6008 → +1753），对 300223 只是减亏，对 000063 有害——不能通用。
5. **板块状态切换**：顺趋势方向真实有效——600487 下跌状态做空T +11822、300223 上升状态做多T +4678、000063 30分 中枢从 -3869 翻 +1636；但它救不了 300223 的中枢策略。
6. **收益高度集中**：正收益集中在 300223 30分 与 600487 15分 两个组合，留一验证后仍成立才建议上实盘。

## 六、注意事项

- “做多T”（先买后卖）在 A 股 T+1 下当日买入部分不能卖出，回测采用与中枢 long 腿一致的简化口径，实盘只能隔日完成，需模拟盘验证差异。
- 板块状态依赖板块指数日K，东财接口被封时自动降级同花顺板块指数，状态分布可能随数据源变化。
- 以上均为历史回测，收益集中度高，建议先小资金模拟盘 2~4 周再放量。
