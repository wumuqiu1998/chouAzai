# 筹码分布 / 主力成本 / 90%成本区间

## 同花顺式筹码模型（东财 CYQ 口径移植）

- 窗口 120 个交易日、150 档价格，精度=max(0.01, (max-min)/149)。
- 每日衰减：筹码 ×= (1 - 换手率)；当日成交量按三角分布填入 [low,high]，峰在 (开+收+高+低)/4。
- 平均成本 = 累计筹码 50% 位价格；90%区间 = 5%~95% 筹码位；集中度 = (p95-p5)/(p95+p5)。
- 实现参考：`run_chip_fundflow_compare.py::calc_chip_distribution`（东财 JS 移植）。

## 参考意义

- 90%区间窄=筹码集中（变盘前/主力控盘）；宽=筹码发散（暴涨暴跌后的真实状态，不是bug）。
- 上沿是解套盘压力，下沿是成本密集支撑；70%区间（15%~85%）更适合做T参考。
- 窗口 60 vs 120 差异通常很小（跨度主要由近期价格范围决定）。

## 主力资金口径

- 东财 push2his 120日分单：主力=超大单+大单（元）；新浪历史仅超大单 r0（缺大单）；push2delay 仅当日精确值。
- push2his 对大陆住宅IP间歇风控（连接被断/空数据）：用裸直连重试（禁用系统代理）+ 缓存，失败降级新浪。
- 对比结论：20日主力净流入方向 vs 20日平均成本移动方向一致/背离，可做资金-筹码交叉验证。
