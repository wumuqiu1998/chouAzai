# 研究方法论（无未来函数 / 假设卡 / 验证）

## 四时间审计

每个字段区分：事件发生时间、数据可用时间、信号计算时间、实际交易时间。可用时间晚于交易时间=数据泄漏。

## 本项目统一约定

- 信号在 T 日收盘后计算完成，最早 T+1 日开盘成交。
- 盘中最后一根未收盘 K 线不参与指标（exclude_last），避免指标抖动。
- 截断一致性测试：指标在 T 时刻只依赖 ≤T 数据 → 全量计算中“截断到 T”必须与“只算到 T”一致（tests/test_no_lookahead.py）。

## 研究假设卡（八项）

市场观察 / 可能机制 / 信号定义 / 数据时间 / 预测目标 / 基准 / 混杂变量 / 失败标准。

## 小样本验证纪律

- 一次只改一个变量；失败实验保留。
- 样本外滚动验证 + Purging/Embargo；开发/验证/盲测集分离。
- 警惕“针尖型”参数（20日有效、19/21日失效）。
- 上线顺序：历史回测 → 样本外 → 模拟盘 → 影子交易 → 小资金 → 分阶段扩大。

## 展示原则（重要）

- K 线只显示成果性标定（积/派/扫/突/破/变、B/S 点、顶/底、分时参考位）。
- 复杂参数/权重/英文术语不进图；需要时放 tooltip、面板说明或本文档。
- 底层策略与理论持续使用，删除图上展示不等于删除计算。
