# 威科夫 + SMC/ICT（理论 → 通俗信号映射）

## 威科夫四阶段

- 吸筹 accumulation：低位横盘（振幅小+均线缠绕+前期涨幅小）+ 缩量；放量长下影 Spring 为确认。
- 拉升 markup：收盘站上 MA20/MA60、MA20 斜率向上。
- 派发 distribution：高位横盘（前期涨幅大）+ 放量滞涨；放量长上影 Upthrust 为确认。
- 下跌 markdown：收盘跌破 MA20/MA60、MA20 斜率向下。
- 主力成本区 = 最近吸筹/派发区间的价格带。

## SMC/ICT

- FVG：三根K线之间的价格缺口（K1.high < K3.low = 看涨缺口；K1.low > K3.high = 看跌缺口），价格有回补倾向。
- OB：一段反向推动前的最后一根K线区域（机构建仓痕迹），回踩是潜在入场区。
- Sweep：突破最近高/低点（打止损）后快速收回，是反转强信号。
- BOS：同方向突破前高/前低（趋势延续）；CHoCH：反向突破（趋势可能改变）。
